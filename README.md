# ML-Scratch 🤖

A **from-scratch implementation** of machine learning algorithms for learning and educational purposes. This repository demonstrates how fundamental ML algorithms work under the hood by implementing them with basic Python, without relying on high-level libraries like scikit-learn.

This is both a **learning resource** and a **practice project** to understand ML algorithms deeply.

## 🎯 Purpose

This project is designed to:
- **Learn** how ML algorithms work internally
- **Understand** the mathematical concepts behind popular ML techniques  
- **Implement** clean, readable, well-documented code
- **Practice** software engineering principles in ML contexts
- **Build intuition** about algorithm trade-offs and design decisions

## 📚 Implementations

Algorithms implemented from scratch (check individual folders for detailed documentation and examples):

### Currently Implemented
- **K-Nearest Neighbors (KNN)** - `Knn/` folder
- **Weighted KNN** - `Knn/` folder

### Planned

## 🚀 Getting Started

### Prerequisites
- Python 3.6+
- No external ML libraries required (only Python standard library)

### Running Examples

Navigate to any algorithm folder and run the example file:

```bash
cd Knn
python knn_example_test.py
python weighted_knn_example_test.py
```

## 📝 How to Use This Repository

1. **Pick an algorithm** from the implementations list
2. **Read the code** - Each implementation is documented with docstrings
3. **Run the examples** - See how the algorithm is used
4. **Understand the math** - Review the mathematical concepts
5. **Experiment** - Modify parameters, test with different data
6. **Compare** - Verify results against scikit-learn's implementation
